PrimeTech Mass Bank Reconciliation

Apply one counterpart account to compatible bank transactions in Odoo 18

Process large selections of unreconciled bank transactions while preserving a separate, balanced journal entry and a complete audit trail for every line.

Key features

  • Contextual mass-reconciliation action for bank transactions.
  • Counterpart account, label, partner, and analytic distribution support.
  • Automatic matching by partner, label, date, and amount, restricted to compatible company, journal, currency, and debit/credit direction.
  • Multi-company access checks and dedicated user and manager roles.
  • Persistent execution logs for accounting auditability.
  • Atomic processing without manual database commits.

Usage

  1. Select one or more bank transactions.
  2. Choose Actions > Mass Reconcile.
  3. Optionally gather matching transactions using the configurable criteria.
  4. Select the manual counterpart account and review the transaction preview.
  5. Click Validate and Reconcile.

Accounting safety

The module processes each statement transaction independently through its existing balanced move. It does not reconcile unrelated selected debits and credits against one another. Transactions must be posted, unreconciled, and compatible before processing.
