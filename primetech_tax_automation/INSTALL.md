# Installation

1. Ajoutez `primetech_tax_automation` au chemin des addons puis mettez à jour la liste des applications.
2. Installez **Fiscalité**. Les dépendances nécessaires sont Comptabilité et Point de Vente.
3. Si les retenues salariales doivent être calculées, installez également votre module de paie. L’intégration est détectée automatiquement ; son absence ne bloque pas l’installation du module.
4. Attribuez les groupes Fiscalité aux utilisateurs concernés et configurez les règles par société.
