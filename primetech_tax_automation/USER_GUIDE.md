# Guide utilisateur

Le menu **Fiscalité** ouvre le tableau de bord de la période en cours. Ajustez les deux dates puis actualisez pour afficher les montants issus des factures, du POS et des journaux de règlement.

Pour une obligation, créez une règle et choisissez sa source : écritures comptables, facturation, Point de Vente, règlement ou paie. Une règle Paie lit les bulletins validés et peut cibler un code de ligne ; sans code, elle utilise la ligne `NET`.

Une déclaration conserve les sources utilisées. Le bouton de recherche présent sur chaque ligne ouvre précisément les pièces qui composent le montant. Les précomptes importés depuis le compte configuré doivent être déclarés admissibles avant leur imputation.

Le PDF et le CSV sont des états de préparation à faire valider par le comptable ou le conseil fiscal avant dépôt officiel.
